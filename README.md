## 🌟 Overview

**NutriMaa AI** is an AI-powered nutrition intelligence and maternal-child health platform designed to eliminate guesswork from healthcare, identify malnutrition risks early, and empower frontline healthcare workers (ASHA & Anganwadi / ICDS) with actionable insights.

---

## 🚀 Quick Start (Running the App)

### Option 1: Direct Browser Opening (Zero Dependencies)
Simply double-click or open `index.html` in any modern web browser (Chrome, Edge, Safari, Firefox).

```bash
# On Windows PowerShell:
Start-Process .\index.html
```

### Option 2: Local HTTP Server (Node.js)
```bash
node server.js
# Then open http://localhost:3000 in your browser
```

## ✨ Key Features & Specifications Implemented

1. **XAMPUS-Inspired Minimalist Loading Sequence**:
   - 1.5s multi-phase telemetry loading sequence (`0%` → `AI INITIALIZING` → `NUTRITION ENGINE` → `HEALTH INTELLIGENCE` → `READY`) with skip option and session storage memory.
2. **Interactive Hero Product OS**:
   - Live tab switcher across **Maternal Health**, **Child Growth**, **ASHA / Frontline Assist**, and **Government Macro Analytics**.
3. **Maternal & Child Health Simulators**:
   - Dynamic trimester calculator, Hemoglobin status tracker, and WHO Multi-centre Growth Reference Study standard curves.
4. **Food Intelligence & AI Computer Vision Scanner**:
   - Searchable, filterable traditional Indian food matrix with affordability indicators and simulated YOLOv8 real-time meal bounding box recognition.
5. **Machine Learning Malnutrition Risk Forecaster**:
   - Random Forest / XGBoost ensemble simulator dynamically computing risk probabilities and intervention pathways.
6. **Multilingual AI Assistant with Voice Support**:
   - Real-time voice recognition and speech synthesis in English, हिन्दी, and বাংলা.
7. **Offline-First Connectivity Simulator**:
   - Interactive online/offline toggle showing local encrypted queuing and automatic cloud sync.
8. **10-Slide Executive Pitch Deck**:
   - Interactive presentation modal with keyboard navigation (`←` / `→`) and presenter notes.
